## 1. Tracing GCD / FPB

**Tracing** = melacak nilai variabel baris demi baris tanpa menjalankan program (dry run).

Algoritma FPB (Euclid):
```
while b != 0 do
    remainder <- a mod b
    a <- b
    b <- remainder
endwhile
output("GCD(", a0, ",", b0, ") =", a)
```

Trace untuk a = 42, b = 15:

| a | b | remainder |
|---|---|---|
| 42 | 15 | 12 |
| 15 | 12 | 3 |
| 12 | 3 | 0 |
| 3 | 0 | |

**Contoh**

```
masukan:
42 15

keluaran:
GCD(42,15) = 3
```

**Penjelasan**

Soal tracing. Yang dinilai tabel nilai `a`, `b`, `remainder` tiap putaran. Cara bikin tabelnya ada di [04-tracing.md](../materi/04-tracing.md).

**Jawaban**

```
program GCD
kamus
    a, b, a0, b0, remainder : integer
algoritma
    input(a, b)
    a0 <- a ; b0 <- b
    while b != 0 do
        remainder <- a mod b
        a <- b
        b <- remainder
    endwhile
    output("GCD(", a0, ",", b0, ") = ", a)
endprogram
```

## 2. Waktu

Konversi waktu dari satuan detik menjadi jam, menit, dan detik.

**Masukan:** nilai `t` dalam detik.

**Keluaran:** `jt jam mt menit dan dt detik`.

**Contoh**

```
masukan:
32

keluaran:
0 jam 0 menit dan 32 detik
```

**Penjelasan**

`div 3600` buat jam, sisanya (`mod 3600`) di-`div 60` buat menit, `mod 60` buat detik.

**Jawaban**

```
program Waktu
kamus
    t, jt, mt, dt : integer
algoritma
    input(t)
    jt <- t div 3600
    mt <- (t mod 3600) div 60
    dt <- t mod 60
    output(jt, "jam", mt, "menit dan", dt, "detik")
endprogram
```

## 3. Voucher

Nomor voucher 4 digit menyimpan rahasia promo:
- **Diskon** jika 2 digit di tengah (sebagai bilangan dua digit) adalah **genap**.
- **Cashback** jika (digit ke-1 + digit ke-3) adalah **kelipatan** digit ke-4.

**Masukan:** bilangan `x` 4 digit.

**Keluaran:** dua baris `Diskon? <bool>` dan `Cashback? <bool>`.

Hati-hati kalau digit ke-4 adalah 0 (tidak boleh modulo 0!).

**Contoh**

```
masukan:
4321

keluaran:
Diskon? true
Cashback? true
```

**Penjelasan**

Ambil digit pakai div/mod. Untuk cashback, cek `d4 != 0` dulu sebelum `mod d4`, soalnya mod 0 itu error.

**Jawaban**

```
program Voucher
kamus
    x, d1, d3, d4, tengah : integer
    diskon, cashback : boolean
algoritma
    input(x)
    d1 <- x div 1000
    tengah <- (x div 10) mod 100
    d3 <- (x div 10) mod 10
    d4 <- x mod 10
    diskon <- tengah mod 2 == 0
    cashback <- d4 != 0 and (d1 + d3) mod d4 == 0
    output("Diskon?", diskon) ; output("Cashback?", cashback)
endprogram
```

## 4. Jumlah Bilangan (digit)

Jumlahkan setiap digit pada bilangan bulat positif.

**Masukan:** bilangan bulat positif `x`.

**Keluaran:** jumlah semua digit `x`.

**Contoh**

```
masukan:
123

keluaran:
6
```

**Penjelasan**

Pola while ambil digit: tambahin `x mod 10`, buang digitnya pakai `x div 10`, ulang sampai `x` habis (0).

**Jawaban**

```
program JumlahDigit
kamus
    x, y : integer
algoritma
    input(x)
    y <- 0
    while x > 0 do
        y <- y + x mod 10
        x <- x div 10
    endwhile
    output(y)
endprogram
```

## 5. Konsekutif

Bilangan **konsekutif**: selisih setiap digit yang bersebelahan adalah **satu**.

**Masukan:** bilangan bulat positif `X`.

**Keluaran:** boolean apakah `X` konsekutif.

> **Catatan:** Contoh ke-2 di slide W07 (1234578 -> true) salah ketik karena 5 ke 7 selisihnya 2, jadi diganti contoh dari W11 (1234321).

**Contoh**

```
masukan:
101010101

keluaran:
true
```

**Penjelasan**

Bandingin digit dari kanan ke kiri, simpan digit sebelumnya di `kanan`. Loop berhenti kalau angkanya habis atau udah ketemu yang selisihnya bukan 1.

**Jawaban**

```
program Konsekutif
kamus
    X, kanan, kiri, selisih : integer
    konsekutif : boolean
algoritma
    input(X)
    konsekutif <- true
    kanan <- X mod 10 ; X <- X div 10
    while X > 0 and konsekutif do
        kiri <- X mod 10
        selisih <- kiri - kanan
        konsekutif <- selisih == 1 or selisih == -1
        kanan <- kiri ; X <- X div 10
    endwhile
    output(konsekutif)
endprogram
```

## 6. Fibonacci

Deret Fibonacci: F0 = 0, F1 = 1, Fi = F(i−1) + F(i−2).  -> 0, 1, 1, 2, 3, 5, 8, ...

**Masukan:** bilangan bulat `N` (N > 1).

**Keluaran:** deret Fibonacci dari suku ke-0 sampai suku ke-N.

**Contoh**

```
masukan:
2

keluaran:
0 1 1
```

**Penjelasan**

Simpan dua suku terakhir di `a` dan `b`. Tiap putaran hitung `c <- a + b`, terus geser: `a <- b`, `b <- c`.

**Jawaban**

```
program Fibonacci
kamus
    N, i, a, b, c : integer
algoritma
    input(N)
    a <- 0 ; b <- 1
    output(a, b)
    for i <- 2 to N do
        c <- a + b
        output(c)
        a <- b ; b <- c
    endfor
endprogram
```
