## 1. FPB (Euclid)

Cari FPB pakai algoritma Euclid. Ini soal tracing favorit, latih tabelnya (ada di [04-tracing.md](../materi/04-tracing.md)).

`42 15` → `GCD(42,15) = 3`

```
program GCD
kamus
    a, b, a0, b0, remainder : integer
algoritma
    input(a, b)
    a0 <- a ; b0 <- b
    while b != 0 do
        remainder <- a mod b
        a <- b
        b <- remainder
    endwhile
    output("GCD(", a0, ",", b0, ") = ", a)
endprogram
```

## 2. Waktu

Detik dikonversi jadi jam, menit, detik.

`3725` → `1 jam 2 menit dan 5 detik`

```
program Waktu
kamus
    t, jt, mt, dt : integer
algoritma
    input(t)
    jt <- t div 3600
    mt <- (t mod 3600) div 60
    dt <- t mod 60
    output(jt, "jam", mt, "menit dan", dt, "detik")
endprogram
```

## 3. Voucher

Nomor voucher 4 digit. Diskon kalau 2 digit tengah genap. Cashback kalau (digit 1 + digit 3) kelipatan digit 4. Awas digit 4 = 0, nggak boleh mod 0.

`4321` → `Diskon? true / Cashback? true`

```
program Voucher
kamus
    x, d1, d3, d4, tengah : integer
    diskon, cashback : boolean
algoritma
    input(x)
    d1 <- x div 1000
    tengah <- (x div 10) mod 100
    d3 <- (x div 10) mod 10
    d4 <- x mod 10
    diskon <- tengah mod 2 == 0
    cashback <- d4 != 0 and (d1 + d3) mod d4 == 0
    output("Diskon?", diskon) ; output("Cashback?", cashback)
endprogram
```

## 4. Jumlah Digit

Jumlahin semua digit. Pola: ambil `mod 10`, buang pakai `div 10`, ulang sampai habis.

`123` → `6`

```
program JumlahDigit
kamus
    x, y : integer
algoritma
    input(x)
    y <- 0
    while x > 0 do
        y <- y + x mod 10
        x <- x div 10
    endwhile
    output(y)
endprogram
```

## 5. Konsekutif

Bilangan konsekutif = selisih tiap digit sebelahan itu 1 (naik atau turun).

`101010101` → `true`

```
program Konsekutif
kamus
    X, kanan, kiri, selisih : integer
    konsekutif : boolean
algoritma
    input(X)
    konsekutif <- true
    kanan <- X mod 10 ; X <- X div 10
    while X > 0 and konsekutif do
        kiri <- X mod 10
        selisih <- kiri - kanan
        konsekutif <- selisih == 1 or selisih == -1
        kanan <- kiri ; X <- X div 10
    endwhile
    output(konsekutif)
endprogram
```

## 6. Fibonacci

Cetak deret Fibonacci dari suku ke-0 sampai ke-N. 0 1 1 2 3 5 8 ...

`6` → `0 1 1 2 3 5 8`

```
program Fibonacci
kamus
    N, i, a, b, c : integer
algoritma
    input(N)
    a <- 0 ; b <- 1
    output(a, b)
    for i <- 2 to N do
        c <- a + b
        output(c)
        a <- b ; b <- c
    endfor
endprogram
```
