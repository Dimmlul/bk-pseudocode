# Minggu 6: perulangan for

## 1. Cetak Barisan

Cetak angka dari n sampai m.

`1 10` → `1 2 3 ... 10`

```
program Cetak_Barisan
kamus
    n, m, i : integer
algoritma
    input(n, m)
    for i <- n to m do
        output(i)
    endfor
endprogram
```

## 2. Sandi

n bilangan 4 digit. Tiap bilangan ambil digit pertama + terakhir, terus totalin semua.

`3 / 2022 4321 5578` → `22`

```
program Sandi
kamus
    n, i, bilangan, jumlah, d1, d4 : integer
algoritma
    input(n)
    jumlah <- 0
    for i <- 1 to n do
        input(bilangan)
        d1 <- bilangan div 1000
        d4 <- bilangan mod 10
        jumlah <- jumlah + d1 + d4
    endfor
    output(jumlah)
endprogram
```

## 3. Cetak String

Cetak string s sebanyak n kali.

`3 HEI` → `HEI HEI HEI`

```
program CetakString
kamus
    n, i : integer
    s : string
algoritma
    input(n, s)
    for i <- 1 to n do
        output(s)
    endfor
endprogram
```

## 4. Bidang Persegi

n persegi, tiap persegi cetak luas sama kelilingnya.

`3 / 5 4 7` → `25 20 / 16 16 / 49 28`

```
program BidangPersegi
kamus
    n, i, s : integer
algoritma
    input(n)
    for i <- 1 to n do
        input(s)
        output(s * s, 4 * s)
    endfor
endprogram
```

## 5. Ngoding

Rata-rata jam ngoding per hari. Hasilnya real, jadi `rata` harus real.

`7 / 8 5 6 5 4 5 6` → `5.571`

```
program Ngoding
kamus
    hari, i, jam, total : integer
    rata : real
algoritma
    input(hari)
    total <- 0
    for i <- 1 to hari do
        input(jam)
        total <- total + jam
    endfor
    rata <- total / hari
    output(rata)
endprogram
```

## 6. Faktorial

n! = 1 x 2 x ... x n. Akumulator perkalian mulai dari 1, bukan 0.

`5` → `120`

```
program Faktorial
kamus
    n, i, hasil : integer
algoritma
    input(n)
    hasil <- 1
    for i <- 1 to n do
        hasil <- hasil * i
    endfor
    output(hasil)
endprogram
```

## 7. Faktor Bilangan

Untuk tiap d dari 1 sampai N, cetak d dan apakah d faktor dari N.

`5` → `1 true / 2 false / 3 false / 4 false / 5 true`

```
program FaktorBilangan
kamus
    N, d : integer
algoritma
    input(N)
    for d <- 1 to N do
        output(d, N mod d == 0)
    endfor
endprogram
```
