## 1. Kelulusan

Lulus kalau (nilai > 55 dan ngerjain tugas) atau nilai > 90.

`65 true` → `true`

```
program LulusGagal
kamus
    nilai : integer
    buat_tugas, status_lulus : boolean
algoritma
    input(nilai, buat_tugas)
    status_lulus <- (nilai > 55 and buat_tugas) or nilai > 90
    output(status_lulus)
endprogram
```

## 2. Karakter Rahasia

5 angka x1..x5, tiap pasangan sebelahan jadi 1 huruf: y = ((xi + xi+1) mod 4096) div 64 + 64. `div 64` sama aja kayak `>> 6`.

`-981 21623 983 22152 1127` → `Baik`

```
program Rahasia
kamus
    x1, x2, x3, x4, x5 : integer
    y1, y2, y3, y4 : char
algoritma
    input(x1, x2, x3, x4, x5)
    y1 <- ((x1 + x2) mod 4096) >> 6 + 64
    y2 <- ((x2 + x3) mod 4096) >> 6 + 64
    y3 <- ((x3 + x4) mod 4096) >> 6 + 64
    y4 <- ((x4 + x5) mod 4096) >> 6 + 64
    output(y1, y2, y3, y4)
endprogram
```

## 3. Persegi Panjang

Keliling 2p + 2l, luas p x l.

`2 2` → `8 4`

```
program PersegiPanjang
kamus
    p, l, K, L : integer
algoritma
    input(p, l)
    K <- 2*p + 2*l
    L <- p * l
    output(K, L)
endprogram
```

## 4. Toko

Harga jual = harga beli + untung 5%.

`1000 2000 3000` → `1050 2100 3150`

```
program Toko
kamus
    barang1, barang2, barang3 : integer
    harga1, harga2, harga3 : real
algoritma
    input(barang1, barang2, barang3)
    harga1 <- barang1 + barang1 * 0.05
    harga2 <- barang2 + barang2 * 0.05
    harga3 <- barang3 + barang3 * 0.05
    output(harga1, harga2, harga3)
endprogram
```

## 5. Permukaan Bola

Luas = 4 x pi x r², pi = 22/7 (pakai constant).

`7` → `616`

```
program PermukaanBola
kamus
    constant PI : real = 22/7
    r, luas : real
algoritma
    input(r)
    luas <- 4 * PI * r * r
    output(luas)
endprogram
```

## 6. Digit Ganda

Bilangan 2 digit, tiap digit digandain. 15 jadi 1155.

`77` → `7777`

```
program DigitGanda
kamus
    x, puluhan, satuan, hasil : integer
algoritma
    input(x)
    puluhan <- x div 10
    satuan <- x mod 10
    hasil <- puluhan*1000 + puluhan*100 + satuan*10 + satuan
    output(hasil)
endprogram
```

## 7. Kapital

Cek karakter itu huruf kapital atau bukan.

`7` → `false`

```
program Kapital
kamus
    k : char
algoritma
    input(k)

```

## 8. Energi

Energi awal E0, kapasitas baterai c, sisa E1. Cycle count = berapa kali c kepake.

`1000 50 0` → `20`

```
program Energi
kamus
    E0, c, E1, cc : integer
algoritma
    input(E0, c, E1)
    cc <- (E0 - E1) div c
    output(cc)
endprogram
```

## 9. Faktor Bilangan

x faktor dari y kalau y habis dibagi x.

`20 5` → `false`

```
program FaktorBilangan
kamus
    x, y : integer
algoritma
    input(x, y)
    output(y mod x == 0)
endprogram
```

## 10. Penduduk

Penduduk = awal + lahir + imigrasi - mati - emigrasi.

`1000 20 5 10 4` → `1011`

```
program Penduduk
kamus
    awal, lahir, imigrasi, mati, emigrasi : integer
algoritma
    input(awal, lahir, imigrasi, mati, emigrasi)
    output(awal + lahir + imigrasi - mati - emigrasi)
endprogram
```

## 12. Gravitasi

Berat = m x g (g bumi 9.8). Tiap planet dikali faktor relatifnya.

`70` → `261 624 686 261 1626 631 611 775 (dibulatin)`

```
program Gravitasi
kamus
    constant G : real = 9.8
    m : real
algoritma
    input(m)
    output(m*G*0.38, m*G*0.91, m*G, m*G*0.38, m*G*2.37, m*G*0.92, m*G*0.89, m*G*1.13)
endprogram
```

## 13. Baris Bilangan

Suku berikutnya = jumlah 2 suku sebelumnya. Dikasih suku 1 dan 2, cari suku 3-5.

`1 1` → `2 3 5`

```
program Baris
kamus
    s1, s2, s3, s4, s5 : integer
algoritma
    input(s1, s2)
    s3 <- s1 + s2
    s4 <- s2 + s3
    s5 <- s3 + s4
    output(s3, s4, s5)
endprogram
```
