## 1. Kelulusan

Mahasiswa **lulus** jika nilai akhir **di atas 55 dan mengerjakan tugas**, **atau** nilainya **di atas 90**.

**Masukan:** nilai akhir (0..100) dan boolean mengerjakan tugas.

**Keluaran:** boolean status lulus.

**Contoh**

```
masukan:
65 true

keluaran:
true
```

**Penjelasan**

Perhatiin kurungnya: `(nilai > 55 and tugas) or nilai > 90`. Kalau kurungnya salah taruh, artinya beda.

**Jawaban**

```
program LulusGagal
kamus
    nilai : integer
    buat_tugas, status_lulus : boolean
algoritma
    input(nilai, buat_tugas)
    status_lulus <- (nilai > 55 and buat_tugas) or nilai > 90
    output(status_lulus)
endprogram
```

## 2. Karakter Rahasia

Pesan rahasia berupa 5 bilangan bulat `x1..x5`. Tiap karakter dibongkar dari dua angka yang bersebelahan:

```
y = ((x_i + x_(i+1)) mod 4096) div 64 + 64
```

(`div 64` sama dengan geser kanan 6 bit: `>> 6`, karena 64 = 2⁶)

**Masukan:** lima bilangan bulat.

**Keluaran:** empat karakter hasil operasi di atas (tanpa spasi).

> **Catatan:** Slide lupa membaca x5 di pseudocode (`input(x1,x2,x3,x4)`), padahal y4 butuh x5.

**Contoh**

```
masukan:
-981 21623 983 22152 1127

keluaran:
Baik
```

**Penjelasan**

Rumusnya tinggal dipakai 4 kali buat 4 pasangan angka. Hasilnya angka ASCII yang dicetak sebagai huruf, jadi tipe `y` itu `char`.

**Jawaban**

```
program Rahasia
kamus
    x1, x2, x3, x4, x5 : integer
    y1, y2, y3, y4 : char
algoritma
    input(x1, x2, x3, x4, x5)
    y1 <- ((x1 + x2) mod 4096) div 64 + 64
    y2 <- ((x2 + x3) mod 4096) div 64 + 64
    y3 <- ((x3 + x4) mod 4096) div 64 + 64
    y4 <- ((x4 + x5) mod 4096) div 64 + 64
    output(y1, y2, y3, y4)
endprogram
```

## 3. Persegi Panjang

Hitung **keliling** (2p + 2l) dan **luas** (p × l) persegi panjang.

**Masukan:** dua bilangan bulat positif `p` dan `l`.

**Keluaran:** `K L` (keliling lalu luas).

**Contoh**

```
masukan:
2 2

keluaran:
8 4
```

**Penjelasan**

Soal rumus biasa, langsung `input`, hitung, `output`.

**Jawaban**

```
program PersegiPanjang
kamus
    p, l, K, L : integer
algoritma
    input(p, l)
    K <- 2*p + 2*l
    L <- p * l
    output(K, L)
endprogram
```

## 4. Toko

Pedagang menetapkan keuntungan **5%** dari modal tiap barang.

**Masukan:** tiga bilangan bulat positif: harga beli tiga barang.

**Keluaran:** tiga bilangan: harga jual masing-masing (harga beli + 5%).

**Contoh**

```
masukan:
1000 2000 3000

keluaran:
1050 2100 3150
```

**Penjelasan**

Harga jual = modal + 5% modal = `modal + modal * 0.05`. Hasilnya bisa desimal, jadi pakai `real`.

**Jawaban**

```
program Toko
kamus
    barang1, barang2, barang3 : integer
    harga1, harga2, harga3 : real
algoritma
    input(barang1, barang2, barang3)
    harga1 <- barang1 + barang1 * 0.05
    harga2 <- barang2 + barang2 * 0.05
    harga3 <- barang3 + barang3 * 0.05
    output(harga1, harga2, harga3)
endprogram
```

## 5. Permukaan Bola

Hitung luas permukaan bola: `4 π r²` dengan **π = 22/7**.

**Masukan:** jari-jari (real).

**Keluaran:** luas permukaan (real).

**Contoh**

```
masukan:
7

keluaran:
616
```

**Penjelasan**

π ditulis sebagai `constant` di kamus biar nggak diketik ulang.

**Jawaban**

```
program PermukaanBola
kamus
    constant PI : real = 22/7
    r, luas : real
algoritma
    input(r)
    luas <- 4 * PI * r * r
    output(luas)
endprogram
```

## 6. Digit Ganda

Gandakan tiap digit bilangan dua digit, misal `15` jadi `1155`.

**Masukan:** bilangan bulat positif dua digit.

**Keluaran:** bilangan empat digit hasil penggandaan.

Catatan: cari nilai tiap digitnya dulu.

**Contoh**

```
masukan:
77

keluaran:
7777
```

**Penjelasan**

Pecah dulu jadi puluhan sama satuan, terus susun ulang: puluhan x 1000 + puluhan x 100 + satuan x 10 + satuan.

**Jawaban**

```
program DigitGanda
kamus
    x, puluhan, satuan, hasil : integer
algoritma
    input(x)
    puluhan <- x div 10
    satuan <- x mod 10
    hasil <- puluhan*1000 + puluhan*100 + satuan*10 + satuan
    output(hasil)
endprogram
```

## 7. Kapital

Periksa apakah karakter yang diberikan adalah **huruf kapital**.

**Masukan:** satu karakter.

**Keluaran:** boolean.

**Contoh**

```
masukan:
7

keluaran:
false
```

**Penjelasan**

Sama kayak alphanumeric, tapi cukup satu rentang `'A'` sampai `'Z'`.

**Jawaban**

```
program Kapital
kamus
    k : char
algoritma
    input(k)
    output('A' <= k and k <= 'Z')
endprogram
```

## 8. Energi

Sumber energi `E0`, kapasitas baterai `c`, sisa energi di baterai `E1`.
**Cycle count** (cc) = berapa kali energi sebesar `c` terpakai.

**Masukan:** tiga bilangan bulat non-negatif `E0 c E1`.

**Keluaran:** bilangan bulat `cc`.

**Contoh**

```
masukan:
1000 50 0

keluaran:
20
```

**Penjelasan**

Energi yang kepake = `E0 - E1`. Dibagi kapasitas pakai `div`, karena yang ditanya berapa kali penuh.

**Jawaban**

```
program Energi
kamus
    E0, c, E1, cc : integer
algoritma
    input(E0, c, E1)
    cc <- (E0 - E1) div c
    output(cc)
endprogram
```

## 9. Faktor Bilangan

Bilangan `x` adalah faktor dari `y` apabila `x` habis membagi `y`.

**Masukan:** dua bilangan bulat positif `x` dan `y`.

**Keluaran:** boolean apakah `x` faktor dari `y`.

**Contoh**

```
masukan:
20 5

keluaran:
false
```

**Penjelasan**

x faktor dari y kalau `y mod x == 0`. Hati-hati, yang dibagi itu `y`, bukan `x`.

**Jawaban**

```
program FaktorBilangan
kamus
    x, y : integer
algoritma
    input(x, y)
    output(y mod x == 0)
endprogram
```

## 10. Penduduk

Jumlah penduduk = penduduk awal + kelahiran + imigrasi − kematian − emigrasi.

**Masukan:** lima bilangan bulat: penduduk awal, kelahiran, imigrasi, kematian, emigrasi.

**Keluaran:** jumlah penduduk.

**Contoh**

```
masukan:
1000 20 5 10 4

keluaran:
1011
```

**Penjelasan**

Rumus tambah-kurang biasa, bisa langsung di dalam `output`.

**Jawaban**

```
program Penduduk
kamus
    awal, lahir, imigrasi, mati, emigrasi : integer
algoritma
    input(awal, lahir, imigrasi, mati, emigrasi)
    output(awal + lahir + imigrasi - mati - emigrasi)
endprogram
```

## 11. Akar Pangkat 3

Tentukan apakah `x` adalah akar pangkat 3 dari `y`.

**Masukan:** dua bilangan bulat `x` dan `y`.

**Keluaran:** boolean.

Catatan: gunakan operasi perkalian.

**Contoh**

```
masukan:
5 125

keluaran:
true
```

**Penjelasan**

Nggak usah nyari akar. Balik aja cara ceknya: x akar pangkat 3 dari y kalau `x*x*x == y`.

**Jawaban**

```
program Akar3
kamus
    x, y : integer
algoritma
    input(x, y)
    output(x * x * x == y)
endprogram
```

## 12. Gravitasi

Berat `W = m × g`. Percepatan gravitasi bumi 9.8 m/s². Gravitasi planet relatif terhadap bumi:

| Planet | Relatif |
|---|---|
| Merkurius | 0.38 |
| Venus | 0.91 |
| Mars | 0.38 |
| Yupiter | 2.37 |
| Saturnus | 0.92 |
| Uranus | 0.89 |
| Neptunus | 1.13 |

**Masukan:** massa tubuh (kg).

**Keluaran:** berat di Merkurius, Venus, Bumi, Mars, Yupiter, Saturnus, Uranus, Neptunus (urut, satu baris).

**Contoh**

```
masukan:
70

keluaran:
261 624 686 261 1626 631 611 775
```

**Penjelasan**

Berat di bumi `m * G`, terus tinggal dikali faktor tiap planet. `G` dijadiin `constant`.

**Jawaban**

```
program Gravitasi
kamus
    constant G : real = 9.8
    m : real
algoritma
    input(m)
    output(m*G*0.38, m*G*0.91, m*G, m*G*0.38, m*G*2.37, m*G*0.92, m*G*0.89, m*G*1.13)
endprogram
```

## 13. Baris Bilangan

Suku pada baris bilangan = jumlah dua suku sebelumnya. Diketahui suku ke-1 dan ke-2,
tampilkan suku ke-3 sampai ke-5.

**Masukan:** dua bilangan bulat (suku ke-1 dan ke-2).

**Keluaran:** tiga bilangan bulat (suku ke-3, ke-4, ke-5).

**Contoh**

```
masukan:
1 1

keluaran:
2 3 5
```

**Penjelasan**

Tiap suku = jumlah dua suku sebelumnya. Hitung urut s3, s4, s5, karena s4 butuh s3.

**Jawaban**

```
program Baris
kamus
    s1, s2, s3, s4, s5 : integer
algoritma
    input(s1, s2)
    s3 <- s1 + s2
    s4 <- s2 + s3
    s5 <- s3 + s4
    output(s3, s4, s5)
endprogram
```
