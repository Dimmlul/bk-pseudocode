## 1. Hello Identitas

Baca nama sama NIM, terus tampilin perkenalan.

`Dimas 1302260001` → `Halo, nama saya Dimas / NIM saya 1302260001`

```
program HelloIdentitas
kamus
    nama, nim : string
algoritma
    input(nama, nim)
    output("Halo, nama saya", nama)
    output("NIM saya", nim)
endprogram
```

## 2. Mencari Posisi

Benda gerak dengan kecepatan tetap. Posisi akhir = posisi awal + kecepatan x waktu.

`3 4 5` → `23`

```
program Jarak
kamus
    posisi, posisi0, kecepatan, waktu : integer
algoritma
    input(posisi0, kecepatan, waktu)
    posisi <- posisi0 + (kecepatan * waktu)
    output(posisi)
endprogram
```

## 3. Cacah Uang

Pecah uang jadi lembaran 10.000, 5.000, 1.000. Kuncinya `div` buat jumlah lembar, `mod` buat sisa.

`129000` → `12 1 4`

```
program Denominasi
kamus
    uang : integer
algoritma
    input(uang)
    output(uang div 10000)
    uang <- uang mod 10000
    output(uang div 5000)
    uang <- uang mod 5000
    output(uang div 1000)
endprogram
```

## 4. Konversi Suhu

Celcius ke Reamur (x4/5), Fahrenheit (x9/5 + 32), Kelvin (+273.15). Semua real.

`50.2` → `40.16 122.36 323.35`

```
program Suhu
kamus
    celcius, reamur, fahrenheit, kelvin : real
algoritma
    input(celcius)
    reamur <- celcius * 4/5
    fahrenheit <- celcius * 9/5 + 32
    kelvin <- celcius + 273.15
    output(reamur, fahrenheit, kelvin)
endprogram
```

## 5. Matematika A

f(x,y) = 1/(3x² + 10) + 10y + 7. Input integer tapi hasilnya real.

`2 2` → `27.045...`

```
program MatematikaA
kamus
    x, y : integer
    f : real
algoritma
    input(x, y)

```

## 6. Matematika B

f(x) = (x³ + 3x) / (x⁴ - 3x² + 4). Pangkat ditulis perkalian berulang.

`1.6` → `3.0957...`

```
program MatematikaB

```

## 7. Tiga Digit

Ambil digit ratusan, puluhan, satuan dari x (x <= 999).

`444` → `4 4 4`

```
program TigaDigit
kamus
    x, d1, d2, d3 : integer
algoritma
    input(x)
    d1 <- x div 100
    d2 <- (x div 10) mod 10
    d3 <- x mod 10
    output(d1, d2, d3)
endprogram
```

## 8. Alphanumeric

Cek karakter itu huruf (a-z / A-Z) atau angka (0-9).

`g` → `true`

```
program Alphanumeric
kamus
    k : char
algoritma
    input(k)
    output(('a' <= k and k <= 'z') or ('A' <= k and k <= 'Z') or ('0' <= k and k <= '9'))
endprogram
```

## 9. Kabisat

Kabisat = habis dibagi 400, ATAU habis dibagi 4 tapi nggak habis dibagi 100.

`2016` → `true`

```
program Kabisat
kamus
    tahun : integer
algoritma
    input(tahun)
    output(tahun mod 400 == 0 or (tahun mod 4 == 0 and tahun mod 100 != 0))
endprogram
```

## 10. Segitiga

Tiga sisi bisa jadi segitiga kalau jumlah dua sisi mana pun > sisi ketiga.

`5 5 5` → `true`

```
program Segitiga
kamus
    a, b, c : integer
algoritma
    input(a, b, c)
    output(a + b > c and a + c > b and b + c > a)
endprogram
```

## 11. Mini Market

Diskon kalau belanja >= 100rb. Kartu kalau mau dibikinin DAN dapet diskon. Cashback kalau belanja >= 200rb DAN dapet kartu.

`1230000 false` → `Kartu? false / Diskon? true / Cashback? false`

```
program MiniMarket
kamus
    belanja : integer
    bersedia, kartu, diskon, cashback : boolean
algoritma
    input(belanja, bersedia)
    diskon <- belanja >= 100000
    kartu <- bersedia and diskon
    cashback <- belanja >= 200000 and kartu
    output("Kartu?", kartu) ; output("Diskon?", diskon) ; output("Cashback?", cashback)
endprogram
```

## 12. Midpoint

Cek ada nggak satu bilangan yang pas di tengah dua bilangan lain. b di tengah a dan c kalau 2b = a + c.

`5 9 1` → `true`

```
program MidPoint
kamus
    a, b, c : integer
algoritma
    input(a, b, c)
    output(2*a == b + c or 2*b == a + c or 2*c == a + b)
endprogram
```

## 13. Dua Lingkaran

Dua lingkaran nggak beririsan kalau jarak pusat > rA + rB.

`5 9 6` → `false`

```
program DuaLingkaran
kamus
    rA, rB, jarak : integer
algoritma
    input(rA, rB, jarak)
    output(jarak > rA + rB)
endprogram
```

## 14. Pramuka

N anggota, masing-masing bawa 5 barang (true/false). Tim siap kalau semua anggota bawa semua barang.

`2 / true true true true true / true true false true true` → `false`

```
program Pramuka
kamus
    N, i : integer
    a, b, c, d, e, siap : boolean
algoritma
    input(N)
    siap <- true
    for i <- 1 to N do
        input(a, b, c, d, e)
        siap <- siap and a and b and c and d and e
    endfor
    output(siap)
endprogram
```
