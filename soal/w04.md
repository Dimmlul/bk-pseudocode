## 1. Hello Identitas

Buat program yang membaca **nama** (satu kata) dan **NIM**, lalu menampilkan:

```
Halo, nama saya <nama>
NIM saya <nim>
```

**Contoh**

```
masukan:
Dimas 1302260001

keluaran:
Halo, nama saya Dimas
NIM saya 1302260001
```

**Penjelasan**

Cuma latihan `input` sama `output`. Perhatiin teks yang dicetak harus persis kayak contoh.

**Jawaban**

```
program HelloIdentitas
kamus
    nama, nim : string
algoritma
    input(nama, nim)
    output("Halo, nama saya", nama)
    output("NIM saya", nim)
endprogram
```

## 2. Mencari Posisi

Sebuah benda bergerak dengan kecepatan tetap `v` meter/detik. Saat ini benda berada pada jarak `d0` meter.
Berapa jarak benda setelah bergerak selama `t` detik?

`posisi akhir = posisi awal + kecepatan × waktu`

**Masukan:** tiga bilangan bulat: jarak awal, kecepatan, lama bergerak.

**Keluaran:** satu bilangan: jarak akhir benda.

**Contoh**

```
masukan:
3 4 5

keluaran:
23
```

**Penjelasan**

Tinggal masukin rumus ke `<-`. Semua nilainya bulat, jadi pakai integer.

**Jawaban**

```
program Jarak
kamus
    posisi, posisi0, kecepatan, waktu : integer
algoritma
    input(posisi0, kecepatan, waktu)
    posisi <- posisi0 + (kecepatan * waktu)
    output(posisi)
endprogram
```

## 3. Cacah Uang

Diberikan nilai uang dalam rupiah. Nyatakan dalam denominasi **10.000**, **5.000**, dan **1.000**.

**Masukan:** bilangan bulat nominal uang.

**Keluaran:** tiga baris: banyak lembar 10.000, 5.000, dan 1.000.

**Contoh**

```
masukan:
129000

keluaran:
12
1
4
```

**Penjelasan**

`div` buat ngitung jumlah lembar, `mod` buat sisa uang yang belum dipecah. Urutannya dari pecahan paling gede ke paling kecil.

**Jawaban**

```
program Denominasi
kamus
    uang : integer
algoritma
    input(uang)
    output(uang div 10000)
    uang <- uang mod 10000
    output(uang div 5000)
    uang <- uang mod 5000
    output(uang div 1000)
endprogram
```

## 4. Konversi Temperatur

Diberikan temperatur dalam Celcius. Konversikan ke **Reamur**, **Fahrenheit**, dan **Kelvin**.

- Reamur = Celcius × 4/5
- Fahrenheit = Celcius × 9/5 + 32
- Kelvin = Celcius + 273.15

**Masukan:** bilangan riil suhu dalam Celcius.

**Keluaran:** tiga bilangan: Reamur, Fahrenheit, Kelvin.

**Contoh**

```
masukan:
50.2

keluaran:
40.16 122.36 323.35
```

**Penjelasan**

Hasilnya desimal, jadi semua variabel pakai `real`.

**Jawaban**

```
program Suhu
kamus
    celcius, reamur, fahrenheit, kelvin : real
algoritma
    input(celcius)
    reamur <- celcius * 4/5
    fahrenheit <- celcius * 9/5 + 32
    kelvin <- celcius + 273.15
    output(reamur, fahrenheit, kelvin)
endprogram
```

## 5. Matematika A

Hitung dan tampilkan:

```
f(x, y) = 1 / (3x² + 10)  +  10y  +  7
```

**Masukan:** dua bilangan bulat `x` dan `y`.

**Keluaran:** nilai `f(x,y)` (bilangan riil).

**Contoh**

```
masukan:
2 2

keluaran:
27.045454545454547
```

**Penjelasan**

x² ditulis `x*x`. Inputnya integer, tapi `f` harus `real` karena ada pembagian `1 / (...)`.

**Jawaban**

```
program MatematikaA
kamus
    x, y : integer
    f : real
algoritma
    input(x, y)
    f <- 1 / (3*x*x + 10) + 10*y + 7
    output(f)
endprogram
```

## 6. Matematika B

Hitung dan tampilkan:

```
f(x) = (x³ + 3x) / (x⁴ − 3x² + 4)
```

**Masukan:** sebuah bilangan berkoma `x`.

**Keluaran:** nilai `f(x)`.

**Contoh**

```
masukan:
1.6

keluaran:
3.0957683741648103
```

**Penjelasan**

Pangkat ditulis perkalian berulang: x³ = `x*x*x`, x⁴ = `x*x*x*x`. Kurungnya jangan sampai kelewat.

**Jawaban**

```
program MatematikaB
kamus
    x, f : real
algoritma
    input(x)
    f <- (x*x*x + 3*x) / (x*x*x*x - 3*x*x + 4)
    output(f)
endprogram
```

## 7. Tiga Digit

Tentukan tiga digit dari bilangan bulat positif `x` (x ≤ 999).

**Masukan:** bilangan bulat positif `x`.

**Keluaran:** tiga bilangan `d1 d2 d3` = digit ratusan, puluhan, satuan.

Petunjuk: satuan didapat dari `x mod 10`.

**Contoh**

```
masukan:
444

keluaran:
4 4 4
```

**Penjelasan**

Pola ambil digit: satuan `x mod 10`, puluhan `(x div 10) mod 10`, ratusan `x div 100`.

**Jawaban**

```
program TigaDigit
kamus
    x, d1, d2, d3 : integer
algoritma
    input(x)
    d1 <- x div 100
    d2 <- (x div 10) mod 10
    d3 <- x mod 10
    output(d1, d2, d3)
endprogram
```

## 8. Alphanumeric

Tampilkan apakah suatu karakter adalah **alphanumeric** (huruf a-z, A-Z, atau digit 0-9).

**Masukan:** satu karakter `k`.

**Keluaran:** boolean.

**Contoh**

```
masukan:
g

keluaran:
true
```

**Penjelasan**

Char bisa dibandingin pakai `<=`, karena sebenernya char itu angka (kode ASCII). Cek tiga rentang, terus gabung pakai `or`.

**Jawaban**

```
program Alphanumeric
kamus
    k : char
algoritma
    input(k)
    output(('a' <= k and k <= 'z') or ('A' <= k and k <= 'Z') or ('0' <= k and k <= '9'))
endprogram
```

## 9. Kabisat

Tahun kabisat adalah tahun yang **habis dibagi 400**, atau **habis dibagi 4 tetapi tidak habis dibagi 100**.
Contoh kabisat: 2016, 2000. Bukan kabisat: 2018, 2200.

**Masukan:** bilangan tahun.

**Keluaran:** boolean apakah tahun kabisat.

**Contoh**

```
masukan:
2016

keluaran:
true
```

**Penjelasan**

Terjemahin kalimat soal langsung ke boolean. "Habis dibagi" = `mod ... == 0`. Outputnya boolean, jadi nggak perlu `if`.

**Jawaban**

```
program Kabisat
kamus
    tahun : integer
algoritma
    input(tahun)
    output(tahun mod 400 == 0 or (tahun mod 4 == 0 and tahun mod 100 != 0))
endprogram
```

## 10. Segitiga

Tentukan apakah tiga bilangan bisa membentuk **segitiga**.
Syarat: jumlah dua sisi mana pun harus **lebih besar** dari sisi ketiga.

**Masukan:** tiga bilangan bulat.

**Keluaran:** boolean.

**Contoh**

```
masukan:
5 5 5

keluaran:
true
```

**Penjelasan**

Ada tiga pasangan sisi yang harus dicek, semuanya wajib benar, jadi pakai `and`.

**Jawaban**

```
program Segitiga
kamus
    a, b, c : integer
algoritma
    input(a, b, c)
    output(a + b > c and a + c > b and b + c > a)
endprogram
```

## 11. Mini Market

Promo ulang tahun mini market:
- **Diskon** jika belanja minimal Rp100.000.
- **Kartu** jika pembeli bersedia dibuatkan **dan** memperoleh diskon.
- **Cashback** jika belanja minimal Rp200.000 **dan** memperoleh kartu.

**Masukan:** total belanja (integer) dan boolean bersedia dibuatkan kartu.

**Keluaran:** tiga baris (lihat contoh).

**Contoh**

```
masukan:
1230000 false

keluaran:
Kartu? false
Diskon? true
Cashback? false
```

**Penjelasan**

Hitung `diskon` dulu, soalnya `kartu` butuh hasil `diskon`, dan `cashback` butuh hasil `kartu`. Urutan baris itu penting.

**Jawaban**

```
program MiniMarket
kamus
    belanja : integer
    bersedia, kartu, diskon, cashback : boolean
algoritma
    input(belanja, bersedia)
    diskon <- belanja >= 100000
    kartu <- bersedia and diskon
    cashback <- belanja >= 200000 and kartu
    output("Kartu?", kartu) ; output("Diskon?", diskon) ; output("Cashback?", cashback)
endprogram
```

## 12. MidPoint

Tentukan apakah salah satu dari tiga bilangan adalah **nilai tengah** dari dua bilangan lainnya
(tepat di tengah-tengah, misal 5 adalah tengah dari 1 dan 9).

**Masukan:** tiga bilangan bulat.

**Keluaran:** boolean.

Petunjuk: `b` di tengah `a` dan `c` kalau `2*b == a + c`.

**Contoh**

```
masukan:
5 9 1

keluaran:
true
```

**Penjelasan**

Yang di tengah bisa a, b, atau c, jadi cek ketiganya terus gabung pakai `or`.

**Jawaban**

```
program MidPoint
kamus
    a, b, c : integer
algoritma
    input(a, b, c)
    output(2*a == b + c or 2*b == a + c or 2*c == a + b)
endprogram
```

## 13. Dua Lingkaran

Tentukan apakah dua lingkaran **TIDAK beririsan**.

**Masukan:** jari-jari lingkaran A, jari-jari lingkaran B, dan jarak kedua titik pusat.

**Keluaran:** boolean `true` jika A dan B **tidak** beririsan.

Petunjuk: dua lingkaran tidak beririsan kalau jarak pusat > rA + rB.

> **Catatan:** Kasus satu lingkaran di dalam lingkaran lain tidak dibahas di slide, jadi diabaikan.

**Contoh**

```
masukan:
5 9 6

keluaran:
false
```

**Penjelasan**

Nggak beririsan berarti jarak pusatnya lebih jauh dari jumlah dua jari-jari.

**Jawaban**

```
program DuaLingkaran
kamus
    rA, rB, jarak : integer
algoritma
    input(rA, rB, jarak)
    output(jarak > rA + rB)
endprogram
```

## 14. Pramuka

Kamu ketua tim pramuka dengan `N` anggota. Tiap anggota dicek kelengkapan **5 item** (boolean).
Tim siap hanya kalau **semua** anggota membawa **semua** item.

**Masukan:** baris pertama `N`. `N` baris berikutnya masing-masing 5 boolean.

**Keluaran:** boolean kesiapan tim.

**Contoh**

```
masukan:
4
true true true true true
true true true true true
true true true true true
true true true true true

keluaran:
true
```

**Penjelasan**

Mulai dari `siap <- true`, terus tiap anggota di-`and` sama barang bawaannya. Sekali ada yang `false`, hasilnya `false` terus sampai akhir.

**Jawaban**

```
program Pramuka
kamus
    N, i : integer
    a, b, c, d, e, siap : boolean
algoritma
    input(N)
    siap <- true
    for i <- 1 to N do
        input(a, b, c, d, e)
        siap <- siap and a and b and c and d and e
    endfor
    output(siap)
endprogram
```
